## Sobre o Projeto

O **Sistema de Controle de Estudos** é uma aplicação web desenvolvida com HTML, CSS e JavaScript puro, sem nenhuma dependência de framework. O objetivo é ajudar estudantes a organizar suas disciplinas, registrar as horas dedicadas a cada uma delas e acompanhar o progresso geral de forma visual e intuitiva.

---

## Funcionalidades

- **Dashboard interativo** com contadores em tempo real de disciplinas, horas estudadas, progresso geral e disciplinas concluídas
- **Cadastro de disciplinas** com nome, professor responsável, carga horária e área do conhecimento
- **Registro de horas** por disciplina de forma prática via modal
- **Barra de progresso individual** calculada automaticamente por disciplina
- **Edição e exclusão** de disciplinas cadastradas
- **Persistência local** dos dados (localStorage)
- **Layout responsivo** para diferentes tamanhos de tela

## Como Executar Localmente

Não é necessário instalar nenhuma dependência. Basta seguir os passos:

```bash
# Clone o repositório
git clone https://github.com/GabrielMGG/Sistema-de-Estudo.git

# Acesse a pasta do projeto
cd Sistema-de-Estudo

# Abra o arquivo index.html no seu navegador
# (ou use a extensão Live Server no VS Code)
```
